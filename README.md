# Noura — كتالوج الأسرة

كتالوج عام مع لوحة إدارة محمية على `/admin.html` لإضافة منتجات جديدة وتعديل الأسعار والكميات ورفع صور PNG/JPG/WebP حتى 5 MB. رابط الإدارة غير ظاهر في واجهة الكتالوج العامة.

## Vercel

Framework: Other. Output Directory: public. لا يحتاج Build Command.

## Supabase

المشروع: `noura-catalog` (`epudixwwrvrhypqcinpq`). المنتجات في `catalog_products` والصور الجديدة في `catalog-images`. الصور الأصلية تبقى في المستودع.

`public/config.js` يحتوي فقط رابط المشروع ومفتاح publishable المخصص للاستخدام العام. لا تضع service_role أو أي secret key في الموقع.

## تفعيل المدير

الدخول باسم مستخدم وكلمة سر فقط. اسم المستخدم يُحوّل داخليًا إلى `<username>@users.noura.invalid`، ولا يحتاج المستخدم أي بريد إلكتروني حقيقي أو تأكيد بريد. اسم المستخدم 3–50 حرفًا إنجليزيًا أو رقمًا مع . _ - ويُوحّد إلى lowercase. أنشئ حساب Auth إداريًا بهذا المعرّف الداخلي وكلمة سر مع email_confirm=true، ثم أضف UUID المستخدم إلى `public.catalog_admins`. لا توجد صلاحية إدارة تلقائية لأي مستخدم، ولا كتابة عامة. لا تضع كلمات السر في GitHub.

لوحة الإدارة لا تصبح قابلة للاستخدام قبل إنشاء الحساب وإضافة صلاحياته. SQL في `database/` هو نسخة توثيقية من الإعداد المطبق، لا تشغله مجددًا على نفس المشروع.

إضافة المنتجات وتعديلاتها تظهر عند فتح أو تحديث الكتالوج دون إعادة نشر. إذا تعذر الاتصال، تظهر القائمة الأصلية مع تنبيه واضح. الحفظ يحمي من الكتابة فوق تعديلات جلسة أخرى.

## التحقق

تم اختبار القراءة العامة ومنع تعديل الزائر ومنع تعديل المستخدم غير المدير والسماح بتعديل المدير داخل transaction تم التراجع عنه. لم يُنشأ حساب مدير دائم بعد، واختبار دخول ورفع صور فعلي يحتاج تفعيله.

Supabase JS 2.57.4 محفوظ محليًا. لا يحتاج تحميل المكتبة من CDN عند التصفح.
