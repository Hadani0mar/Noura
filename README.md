# كتالوج الأسرة

كتالوج عربي يعرض 25 صنفًا بصورها وأسعارها وعدد العبوات، حسب قائمة سبتمبر 2026.

## النشر على Vercel

استورد هذا المستودع ثم اختر:

- Framework Preset: Other
- Root Directory: اتركها الافتراضية
- Build Command: اتركها فارغة
- Output Directory: public

لا يحتاج الموقع أي مفاتيح أو تسجيل دخول. للسماح للزوار، عطّل حماية نشر الإنتاج إذا كانت مفعّلة.

الأسعار من الملف الأصلي؛ العملة غير محددة فيه، ولا تمثل الأرقام أسعارًا محسوبة للوحدة المفردة.
